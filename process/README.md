## How we worked

1. **Research and concept.** We studied NASA sources: the Systems Engineering Handbook, Cassini, Saturn facts, ECLSS and the DSN. We picked the Space Mission Design Game challenge. An early draft sent the mission to Mars. The final version goes to Saturn.
2. **Master design document.** The team wrote the full rules: subsystem options, costs and masses, the 105-credit budget, the 130-unit mass limit, the six emergencies, the three return routes, the scoring, and worked examples with exact numbers.
3. **Art direction.** We chose a cartoon style with our own original characters and a fixed color palette. The team's reference images were used only as inspiration. Everything in the game is drawn by code.
4. **Implementation.** The code was written with AI coding assistance (Anthropic Claude) from our design document. 46 automated tests check the game against the document's worked examples.
5. **Review.** The team reviewed the game against the design document. A team-only feedback tool built into the game lets testers report corrections from inside the game.
